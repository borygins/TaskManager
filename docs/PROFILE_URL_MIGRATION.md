# Миграция ссылки на профиль

Новая версия приложения хранит ссылку на внешний профиль клиента в колонке `clients.profile_url`. Для существующей базы колонку нужно добавить до запуска обновлённого приложения.

## Запуск

1. Остановите приложение.
2. Выполните из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts\migrate_profile_url.py --database task_manager.sqlite3
```

3. Убедитесь, что команда сообщила об успешной проверке целостности.
4. Запустите приложение.

Скрипт самостоятельно создаёт проверенную резервную копию через SQLite Backup API в папке `backups`. Имя файла содержит `before_profile_url`. Изменение выполняется транзакционно, фиксируется в `schema_migrations` и безопасно распознаётся при повторном запуске.

Если промежуточный вариант миграции этой ссылки уже был применён, скрипт переименует прежнюю колонку и сохранит находящиеся в ней адреса.

Скрипт не запускается приложением автоматически. Не запускайте его одновременно с работающим приложением.
