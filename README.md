# TaskManager

Веб-задачник для менеджеров по продажам с несколькими воронками, авторизацией по табельному номеру, назначением клиентов, комментариями, звонками, импортом и экспортом Excel и ежедневным бэкапом SQLite.

## Что уже реализовано

- авторизация по табельному номеру и паролю;
- роли `manager` и `boss`;
- общие воронки для всех пользователей;
- уникальные клиенты по ИНН;
- один клиент закреплен только за одним менеджером;
- клиент может состоять в нескольких воронках одновременно;
- явный признак клиента в нескольких воронках;
- карточка клиента с редактированием и сохранением одним действием;
- журнал активности за текущий день;
- массовая загрузка задач через Excel-шаблон;
- выгрузка текущих задач в Excel;
- ежедневный локальный бэкап базы;
- современный темный интерфейс.

## Стек

- Python 3.13
- FastAPI
- SQLAlchemy Async ORM
- SQLite в WAL-режиме
- Jinja2 Templates
- HTML + CSS
- openpyxl
- APScheduler

## Быстрый старт

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

После первого запуска приложение создаст:

- базу `task_manager.sqlite3`;
- тестовую учетку начальника `01333777 / admin`;
- тестовую учетку менеджера `01666222 / manager`;
- две воронки: `Доля рынка` и `Спарк`.

## Входные данные

- URL: `http://<ваш-ip>:8000`
- позже можно поставить HTTPS через корпоративный reverse proxy или локальный сертификат

## Ограничения текущего MVP

- пока нет Alembic-миграций;
- пока нет постраничного поиска и фильтров;
- HTTPS не поднимается самим FastAPI, его лучше выносить на внешний прокси;
- пока используется SQLite, но структура подготовлена к переходу на PostgreSQL.
